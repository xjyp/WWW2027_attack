% 第一段（背景与重要性）：
% 介绍成对偏好评估（pairwise preference evaluation）在 LLM 评估与对齐（Chatbot Arena、RLHF、DPO）中的核心作用
% 第二段（现有攻击与研究缺口）：
% 指出现有针对 LLM 偏好判断的攻击可分为回复级操纵（如 JudgeDeceiver，向候选回复注入优化的对抗序列）和提示级操纵（如 PreferAttack，优化对抗提示以翻转判断），但二者都依赖较强的攻击者能力假设，目前尚不清楚在无法访问核心评估内容、仅能修改有限外部输入的严格受限条件下，偏好操纵是否仍然可行。

% 第三段（核心发现与中心挑战）：
% 我们发现即使在受限条件下偏好操纵依然可行：简单的自然语言线索在部分场景即可造成大量偏好翻转（操纵门槛出人意料地低），但不同攻击在不同样本子集上奏效、呈现显著的异质性与互补性，因此核心挑战从"能否操纵"转变为"如何系统性构建多样化攻击形式并识别互补的攻击组合"。

% 第四段（两个具体技术挑战）：
% 应对上述挑战需克服两个紧密关联的局限：其一，受限访问下难以构建有效且可系统搜索的攻击空间（固定的内容无关提示灵活性不足，而无约束生成/离散优化又可能牺牲语义连贯性）；其二，有限查询预算下需要利用细粒度边际反馈来区分互补候选与冗余候选，而聚合成功率无法捕捉这种互补性。

% 第五段（本文方法 PDA-KAS）：
% 为此，我们在输入不可见、注入位置受限的设定下提出 PDA-KAS——一个将因子化攻击空间（将攻击分解为"论证方向"与"包装模板"两个维度）与覆盖感知候选评估（结合翻转表现与相对当前成功集的边际增益）相结合的结构化搜索框架，在有限查询预算内系统探索多样攻击策略并识别互补组合。

% 第六段（贡献总结，可用 itemize）：
% 总结本文三项贡献：(1) 构建结构化、内容无关的因子化攻击空间，兼顾多样性、有效性与语义自然性；(2) 提出细粒度、覆盖感知的评估机制，以更少的查询优先发现贡献新翻转的互补策略；(3) 开展受限访问下偏好操纵的系统性实证研究，刻画自然语言攻击在多种数据集与评判模型上的有效性与异质性，并验证 PDA-KAS 在扩大攻击覆盖率的同时减少冗余查询。
